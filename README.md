# maya-scatter-brush

Maya Scatter Brush Tool

This tool is meant to create multiple duplicates of an item, as you would in Photoshop. Let's artists scatter items quickly
and effectively throughout a scene. By importing objects into a small library, the brush can output and randomize items as well.

You can control density, flow, scale, and rotation offset. Also has an eraser tool to quickly remove all or sections of a stroke.
While keeping all meshes organized and within groups.

Using the tool requires a mesh to interact with.
